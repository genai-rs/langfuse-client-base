A low-level async Rust client for the [Langfuse](https://langfuse.com) API: one function per operation and a type per
schema of Langfuse's [published OpenAPI specification](https://cloud.langfuse.com/generated/api/openapi.yml). The code
is generated by [timvw-rust](https://github.com/timvw/openapi-generator-timvw-rust) from the upstream spec; nothing is
patched afterwards. Requests go through [`timvw-rust-runtime`](https://docs.rs/timvw-rust-runtime), a
[tower](https://docs.rs/tower) service (reqwest unless you replace it) with retries.

Most applications want [langfuse-ergonomic](https://github.com/genai-rs/langfuse-ergonomic), built on this crate, with
batching, environment-based configuration and OpenTelemetry integration. Use this crate directly for raw access to
every endpoint.

## Quick start

```bash
cargo add langfuse-client-base
```

```rust,no_run
use langfuse_client_base::apis::{configuration::Configuration, health_api};

# async fn run() -> Result<(), Box<dyn std::error::Error>> {
let mut configuration = Configuration::new();
configuration.base_path = "https://cloud.langfuse.com".to_owned();
configuration.basic_auth = Some((
    std::env::var("LANGFUSE_PUBLIC_KEY")?,
    Some(std::env::var("LANGFUSE_SECRET_KEY")?.into()),
));

let health = health_api::health_health()
    .configuration(&configuration)
    .call()
    .await?;
println!("Langfuse {} is {}", health.version, health.status);
# Ok(())
# }
```

## Key features

- **Every endpoint** of the spec, plus the published v3 bindings for self-hosted servers that still serve them
  ([usage](https://github.com/genai-rs/langfuse-client-base/blob/main/guides/usage.md)).
- **Typed models and errors**: unions decode by their tag, enums accept values the spec does not list yet, and error
  responses decode into a typed error per operation
  ([usage](https://github.com/genai-rs/langfuse-client-base/blob/main/guides/usage.md#errors)).
- **A tower client**: retries of `429`, `408`, `5xx` and failed connections honouring `Retry-After`, timeouts,
  logging, your own middleware, and per-call headers, query parameters or base URL
  ([HTTP client](https://github.com/genai-rs/langfuse-client-base/blob/main/guides/http-client.md)).
- **rustls or native TLS, and WebAssembly** (`wasm32-unknown-unknown`)
  ([platforms](https://github.com/genai-rs/langfuse-client-base/blob/main/guides/platforms.md)).
